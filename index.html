Miami University IT Support / Knowledge Base Chatbot

Welcome! This chatbot is designed to help Miami University students and faculty to quickly troubleshoot common IT issues and find answers to frequently asked questions. All information provided by this chatbot is sourced from the official Miami University Knowledge Base.

Hi, this is my senior capstone project! I built this chatbot using Botpress and embedded it into this HTML page using GitHub. I also created a web scraper with Python and Beautiful Soup in VS Code to gather data for the chatbot. The idea is to help Miami University students and faculty get quick IT support without having to navigate multiple Knowledge Base links.

Click the chat bubble in the bottom right corner and type your question. You can also select quick response buttons. For example, you can ask:

  • How do I reset my password?
  • How do I connect to the campus Wi-Fi?
  • How do I setup Duo?
  • How do I install the VPN?

If the chatbot can't solve your issue, it will provide additional resources to get help, or you can go to the Miami Technology Services Page/

Note: This chatbot is a student project and is not officially affiliated with Miami University
